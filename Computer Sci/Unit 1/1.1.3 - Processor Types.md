
There are 2 types of processors 

## CISC

CISC aims complete the task in as few lines of assembly as possible - this means that this CPU would have more complex circuitry to be able to understand and execute a series of instructions.

A CISC processor could include a specific instruction for multiplying two numbers. for example MULT

MULT is an example of a complex instruction. 

It resembles the original command from a high level language: 
product = num1 * num2

This means that the compiler would have to do little  work when translating high level code into assembly.

However, this complex instruction might take more than one machine/clock cycle to execute 

## RISC

RISC processors aim to use simple instruction that will be executed within a single clock cycle.
