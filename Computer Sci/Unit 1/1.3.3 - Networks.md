### Key Concepts to Remember

|Concept|Essential distinction|
|---|---|
|Internet vs WWW|The internet is the interconnected network infrastructure; the WWW is a service that runs on it.|
|TCP vs UDP|TCP prioritises reliable transmission; UDP is connectionless and prioritises low-overhead, fast delivery.|
|IP vs MAC|IP addresses support routing between networks; MAC addresses identify network interfaces for local-link delivery.|
|LAN vs WAN|A LAN covers a relatively small area; a WAN connects networks across larger geographical areas.|
|Circuit vs packet switching|Circuit switching reserves a dedicated connection; packet switching sends data in independently routed packets.|
|Hub vs switch|A hub broadcasts incoming data; a switch forwards data towards the intended device.|
|Router vs modem|A router forwards data between networks; a modem converts signals for transmission over its access medium.|
|Client-server vs peer-to-peer|Client-server centralises services; peer-to-peer distributes resources and responsibility between devices.|
|HTTP vs HTTPS|HTTPS adds encryption and authentication to protect web communications.|
|POP vs IMAP vs SMTP|POP retrieves incoming email; IMAP synchronises email on the server; SMTP sends outgoing email.|

### TCP/IP: The Journey of Data

**Application → Transport → Internet → Link**

1. **Application:** Application protocols define how services exchange data, e.g. HTTP, HTTPS and FTP.
    
2. **Transport:** TCP or UDP handles transport; TCP uses port numbers and segments data for transmission.
    
3. **Internet:** IP adds source and destination IP addresses so packets can be routed.
    
4. **Link:** Data is transmitted over the local network using link-layer addressing and frames.
    

At the receiving device, data travels back up the layers, with headers and other encapsulation information processed along the way.

### Network Models: The Trade-off

**Client-server:** Centralized management, security, updates and backups, but greater cost and dependence on the server.

**Peer-to-peer:** Cheaper and simpler for small networks, without dependence on a central server, but with more distributed security and backup responsibilities.

##### TCP/IP and UDP

The Transmission Control Protocol (TCP) provides error-free transmission between two routers.

The Internet Protocol (IP) routes packets across a wide area network (WAN).

Together, they make up the TCP/IP protocol stack, the foundation of communication over the internet.

The User Datagram Protocol (UDP) uses a simple, connectionless transmission model.

It's is an alternative to TCP but has **no error checking**.

It is used to send short messages using datagrams, where speed is more important than accuracy.

It maintains a open two way connection ideal for online gaming. 

It largely obsolete now as it's significantly less reliable than than TCP.

##### HTTP/HTTPS

The Hypertext Transfer Protocol (HTTP) is a way for client and server to send and receive requests and deliver HTML web pages.

It is the fundamental protocol of the **World Wide Web** (WWW).

The Hypertext Transfer Protocol Secure (HTTPS) is effectively the same as HTTP, except it adds encryption and authentication.

HTTPS should be used whenever a website deals with sensitive information such as passwords or bank accounts details.

##### FTP

The File Transmission Protocol (FTP) is a protocol used for sending files between computers, normally over a **wide area network (WAN).**

Often people use FTP clients - software applications that sit on top of the actual FTP protocol.

When you interact with the program, the client generates and send the appropriate FTP commands.

##### POP/IMAP/SMTP

Three popular protocols that are used in conjunction with mail servers to deal with emails.

Mail servers can be thought of a virtual post office handing incoming and outgoing emails.

**Simple Mail Transfer Protocol (SMTP)** transfers outgoing emails between and from emails clients to servers.

**Post Office Protocol (POP)** retrieves emails from a mail server and transfers them to your device, removing them from the server in the processes.

Internet Message Access Protocol (IMAP) keeps emails on the the mail server maintaining
synchronicity between devices.

#### The Concept of Layers 

The concept of layering is to divide the complex task of networking into smaller, simpler tasks that work in tandem with each other.

The hardware and/or software for each layer has defined responsibility, and each one provides a service to the layer above it.

The advantages of layering include: 
- Reducing a complex problem into smaller sub-problems 
- Devices can be manufactured to operate at a particular layer.
- Products  from different vendors will work together.

#### TCP/IP protocol - In practice 

"Computer system analysis is like child rearing; you can do grievous damage but you cannot ensure success."

**Application**

- We are going to pass this message down through the layers of the TCP/IP stack to see what happens to it at each stage before it sent out to another device in the network.
- The application layer uses an appropriate protocol relating to what ever application is being used to transmit data.
- This message is being sent via a web browser - so, the list of appropriate protocols would include HTTP, HTTPS, FTP, etc.

**Transport** 

-  The transport layer uses the TCP part of the stack as well as other conversation protocols like UDP.
- It is responsible for establishing an end-to-end connection and maintaining conversation between application processors.
- These protocols use **port numbers** to track sessions and add this information to the header.
- Once the connection is made, the transport layer splits the data into **packets**. It adds to each packet:  
	-   Its number/sequence 
	- The total number of packets 
	- The port number that the packet should use
-  Packets  are number so they can be reassembled in the correct order.



**Internet**

- The internet layer uses the IP part of the stack.
- It adds to each packet:
	-  Source IP address
	- Destination IP address 
- All routers operate at this layer. They use the IP address to find out where the packets are heading. We now have what is known as a socket: 
	- Socket = IP address + port 
	- For example, 127.56.87.2:80
- We now know:
	- The device the packet is being sent to (IP address)
	- The application on that device that needs the packet (port).


**Link Layer**

- The link layer represents the actual physical connection between network network devices.
- It is responsible for adding the unique  Media Access Control (MAC) address of the: 
	- Source device 
	- Destination device 
- When transmitting data between router over wide area network (WAN), the MAC address is changed at each hop on the route.
- At this point the packets a now called frames



##### Reasons for having both a MAC and IP address 

- Communication between two devices on the same local area network (LAN) only requires the link layer, which creates a frame using the MAC addresses.
- Communication between two devices on different networks (WAN) requires both the network layer, which uses IP addresses to create a packet, and the link layer creates the  frame.
- In practice, communication via modern LANs also make use of IP addresses, treating the local network as if it were a wide network.
- Every physical device should have a unique MAC address. However, for a router, storing the references to every MAC address in existence would be unmanageable  - it would take too long to find a particular address to decide which connection to route traffic down.
- Therefore, switches learn and store MAC addresses for connected devices only, while routers cache some IP addresses.
- In essence, it is quite similar to how we would a letter: 
	- Your MAC address tells me who you are
	- Your IP address tells me where you are



- For example say you want to send a message to another device on a local area network, but you don't know which one. It perfectly fine to use just The MAC Addresses at this level.
- Think of it like being in a classroom - you want to talk to Sarah, but you don't know who Sarah is.
- You can simply call out (broadcast) to the rest of the class, "Who is Sarah?" Everyone hears your broadcast but only  Sarah replies.
- Sarah has in essence, given away who she is - her MAC address.
  
  
- Note that MAC addresses need to be unique 
  
-  This approach can't possibly work on the Internet because there are too many devices.
  
-  Using our example from before, Sarah won't even be able hear you. You can't simply broadcast out to the whole world in the hope Sarah will respond.
- In essence, the IP address tells us roughly where we need to head, even if we don't know the person (device) our message is for.
- Although this example is highly abstracted, it helps to explain why need both a MAC address and IP address to route traffic over a wide area network like the internet.



##### How this applies to TCP/IP

- If the two hosts are on the same network, delivery is simple - one host can simply send to the other.
- A host may need to broadcast first if it doesn't already know the destination MAC address - The ARP protocol achieves this.
- As traffic passes through the switch, the switch examines source and destination MAC addresses and learns which address applies to each device, eliminating the need for broadcasting in the future.
- Modern routers are both routers and switches, performing both LAN switch and WAN routing 
  
  
  - If the two hosts are on different networks - for example, sending something over the internet - the data will transmitted via router.
  - The destination MAC address will be the address of the router 
  - When the frame reaches the router, the router works out where it needs to send the packet by looking at the destination IP in the header.
  - The router then sets it own MAC address as the source and the next device as the destination. The router can also use the ARP protocol to find the destination MAC address if it doesn't already know it.
  - If there are several routers on the path to the destination, the source and destination MAC addresses will be overwritten at every top.

#####  Wrapping it up

- The original message is split apart and wrapped up in segments
- These segments are then wrapped up in packets which, in turn, are wrapped up in frames.
- One the frames reach their final destination, they will travel up through the layers of the TCP/IP stack in reverse order, stripping off the headers and tails as they go.
- Finally, the destination application receives the message.

#### Packet Switching and Circuit Switching 

##### Circuit Switching

Circuit switching provides the basis for traditional telephone networks.

Circuit switching creates a temporary and dedicated link of fixed bandwidth between the source and destination that only lasts until the transmission is complete.

Using this method guarantees the quality of the transmission through dedicated bandwidth, making circuit switching excellent for data that needs a constant link end-to-end such as real-time video.

The downside is that a lot of the potential bandwidth can be wasted.

##### Packet Switching 

Packet switching breaks streams of data into smaller blocks, each sent independently of one another.

At each node, packets are sent via whichever route the node decides is the least congested - this maximizes bandwidth but doesn't guarantee the quality of the transmission.

It also means that packets can take different routes to their destination and may arrive out of order.

Packet Switching is more affordable and efficient than circuit switching as all bandwidth can be used at once. It also requires less complex infrastructure and can easily respond of parts of the network fail

### Network Security

When we connect computing devices together via a network allows  them to share data and subsequently connect them to the internet, the become vulnerable to attack or misuse.

All network need protection from unwanted intrusion and hacking.

The aim of network security is to: 
- Only allow authorized users to access what they need.
- Prevent unauthorized access.
- Minimize the potential damage caused by unauthorized access


## Security Issues and threats 

### Hackers 

A hacker is a person who attempts  to gain access to computer system with the intent of damaging data or somehow harming that system

Hackers come in many forms and not all of them have malicious intent

These are :

- Black Hat hackers: These are your traditional hackers as often portrayed  in TV and films. 
  They attempt to gain access via nefarious means, typically to steal company secrets or cause damage.
  
-  White Hat hackers: These are security experts (often ex-hackers) employed by a company. Also known as ethical hackers, they use their expertise to try and find vulnerabilities and fix them. 
  
- Grey Hat hackers: These hackers sit somewhere between the other two. They are not employed by a company, but they still attempt to locate flaws into company-wide computer systems as a hobby. This is technically still illegal, but they make the company aware of the vulnerability found.


### Malware

**Malware** is an umbrella term that covers any computer code written with the intent to frustrate or harm.

Malware can have a wide range of effects depending on what type is was and these normally: 

- Deleting, corrupting or encrypting files
- Causing Computers to crash, reboot or slow down
- Reducing network speeds 
- And Logging and sending keyboard inputs to hackers


Examples Include 

Viruses - The most well known and popularized form of malware, these are bits of code capable of copying themselves and spreading throughout a system.

They are typically designed to have a negative effect like corrupting a file system or destroying data.

Spyware - This is a form of malware that covertly obtains information about a user's computer by transmitting data from their device. Such as: Internet Surfing Habits, Email addresses, Visited web pages, Downloads/download habits, Passwords, Credit card numbers, Keystrokes and Cookies.


### Denial of Service Attack (DoS)

A denial of service (**DoS**) attack is when an attacker floods a server with useless traffic, causing the server to become overloaded

Past DoS attacks exploited the limitations of the [TCP/IP Stack](<#TCP/IP Protocol Stack>).

These attacks often target web servers of high profile organizations such as banks, large scale e-commerce businesses and the government. 

Though DoS attacks do not typically result in the theft or loss of data or other assets, they can cost a lot of time and money to handle.


A variant of this is called a distributed denial of service (**DDoS**) attack.

A DDoS attack occurs when multiple system orchestrate a synchronized DoS attack against a single target.

There are several ways this can be done, however this is more than we actually need to know, but the basics is that instead of being attacked from one location the target is bombarded from all angles.

An example of this is multiple computers becoming infected and then become a puppet that performs its own DoS attack often without the owners knowledge.

### Minimizing threats

#### Firewall

A firewall is piece of software or harder (sometimes both) configured to let only certain types of traffic through it.

It can be set up to prevent:

- Unauthorized traffic from outside a [LAN](<#Local area networks (LANs)>)
- User in a LAN from accessing parts of the internet 
  
A firewall can block certain ports and types of traffic. It can also inspect data trialling to see it is looks suspicious.

Operating systems and home routers come with built-in firewalls. More sophisticated ones are also available to purchase separately.


#### Secure Password Systems

A common method of preventing unauthorized access to a system is requiring users to log in with predetermined credentials such as a user and password.

These systems can often be made more secure by implementing password rules.

However, it is well-documented that enforcing overly strict rules often causes users to write their password down so they don't forget it - defeating the object entirely.

#### Up-to-date software and anti-malware software

A common method of preventing and minimizing threats is to install **anti-malware** software.

These applications often come pre-installed with your operating system, but you can purchase others from dedicated vendors.

It is also crucial to ensure software - especially operating system and anti-malware software - is always updated with the latest patches.

When software is first released, it is often far from perfect. Early builds can contain bugs or flaws. Which can then be exploited by [Malware](<#Malware>)

As flaws are discovered, companies develop fixes, known as patches.


#### Proxies 

A proxy is simply a physical device placed between a network and a remote source.

All traffic travels through the device on its way in and out a network.

For example, a proxy could handle web page requests. If the page is not on the proxy's banned list, it will pass on the request.

It can also look at the page and its contents and choose whether to pass it back to the user or not. 

A proxy ensures there is no direct, physical connection between a single user and a remote source.

#### Encryption 

Encryption is the process of turning plain text into an unreadable form.

The plain text is encrypted using an algorithm and a unique key now only someone with the appropriate key will be able to translate the cyphertext back into readable form.

Encryption doesn't stop you from being hacked, but it makes it that stolen data is basically useless to the hacker.



### "The Cold, hard truth"

However, this can be mitigated through user training and education programs, but the risk can never be removed entirely.

A modem transforms digital information from your computer into analogue signals that can be transmitted using wires.

It can also translate incoming analogue signals back into digital data that your computer can understand.

It does this by modulating and demodulating electrical signals sent through phone lines, coaxial cables or other types of wiring.

Most standalone modems have only two ports: One that connects outside and An Ethernet port that connects to a computer or [router](<#Router>)

### Network Interface Controller (NIC)

Without a network interface controller (NIC), a computer cannot to a network.

A NIC allows both wired and wireless communications between computers on a [LAN](<#Local area networks (LANs)>) or connected to a large-scale network using the [Internet Protocol (IP)](<#TCP/IP and UDP>).

A NIC is both a physical and data link layer device, providing the necessary circuitry for physical layer processes and some data link layer processes to run on it.


### Wireless Access Point (WAP)

A wireless access point (WAP) is a device that creates a wireless local area network (WLAN) usually in a home or office building.

It connects to a wired [Router](<#Router>), [Switch](<#Switch>), [Hub](<#Hub>) via an Ethernet cable and projects a Wi-Fi signal within a designated area.

For example if a school wants to enable Wi-Fi access in reception but doesn't have a router within range. It can install a WAP near the front desk and run an Ethernet cable through the ceiling to a server room.

Wi-Fi range is limited and easily interrupted by various construction materials, so most businesses use multiple WAPs for full coverage.
### Hub

A hub allows you to connect multiples devices to one network.

It operates on the physical layer and it considered a passive device. In other words, it simply broadcasts the transmissions it receives to all other connected devices.

Unfortunately, that means the network can easily become flooded with unnecessary traffic.

It is purely a hardware device - there is no software installed on it.

Hubs are typically much slower than [switches](<#Switch>) in terms of data transfer.
### Switch

A switch also allows you to connect multiple devices to one network, it operates on the data link layer and is an active device meaning it can inspect transmissions and route them to the correct device, keeping unnecessary traffic to a minimum.

A switch typically has software installed on it for admin and config purposes.

These are typically much faster than hubs in terms of data transfer.

## Network Models 

### Client-Server Model 
![](</Computer Sci/Images/Pasted image 20261023201418.png>)

In a client-server network model a server:

- Control access and security for a shared file store.
- Manages access to the internet.
- Manages printing jobs
- Provides email services
- Runs regular backups of data 


A client makes requests to the server for data, connections and other services.

These are best suited to organizations with numerous computers or situations where many computers need access to the same information.

| Advantages                                          | Disadvantages                                     |
| --------------------------------------------------- | ------------------------------------------------- |
| Easier to manage file security                      | Can be expensive to set up and maintain.          |
| Easier to back up shared data                       | Requires IT specialists to maintain.              |
| Easier to install software updates to all computers | The server is a single point of failure           |
|                                                     | User will lose network access if the server fails |

### Peer to Peer model 
![](</Computer Sci/Images/Pasted image 20261023201449.png>)

With a peer to peer model: 

- A peer is computer connected to the network.
- A peer is equal to all other peers.
- Peers serve their own files to each other.
- Each peer is responsible for its own security and data back up.
- Peers usually have their own printers.
- Peers can send print jobs to another per to process, but that means that peer must be on to communicate with the printer 

These are networks are best suited to smaller organizations with fewer computers or where fewer users need to same data 

| Advantages                         | Disadvantages                                          |
| ---------------------------------- | ------------------------------------------------------ |
| Very easy to maintain              | The network is less secure                             |
| Specialist Staff are not required  | Users will need to manage their own back-ups           |
| No dependency on a single computer | Can be difficult to maintain a well-ordered file store |
| Cheaper to set up                  |                                                        |
| No expensive hardware              |                                                        |
