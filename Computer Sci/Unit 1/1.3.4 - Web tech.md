## Website Development 

### HTML

HTML stands for Hyper Text Markup Language, the standard markup language for web pages.

HTML elements are building blocks of HTML pages and are represented by the <> tags.

HTML elements can have attributes that provide additional information about the element.

Attributes come in name/value pairs (e.g. charset = "utf-8").

Web pages coded using HTML are read by web browsers, that decode the tags and render the page.

These tags include 

```html
<html></html> 
<link></link>
<head></head>
<title></title>
<body></body>
<h1></h1> // and 2,3
<img></img>
<div></div>
<a></a>
<form></form>
<input></input>
<p></p>
<li></li>
<ol></ol>
<ul></ul>
<script></script>
```


`<html>` Starts the HTML document, these are non-visual

`<head>` This is the container for metadata that is placed between the `<html>` and `<body>` tags, this is also non-visual 

`<title>` This defines the title of the document, the title must be text only and is only shown in the title bar or page tab. → This is also a required tag for all HTML documents.

`<body>`This defines the document's main text and contains any headings, paragraphs, images, hyperlinks, tables and lists, 

There can only ever by one `<body>` tab in an HTML
